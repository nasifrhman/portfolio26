# Md. Nasifur Rahman — Portfolio Website

A modern, high-performance, and editorial portfolio web application for **Md. Nasifur Rahman** (Software Engineer & Back-End Developer at Sparktech Agency) built with **React 19, TypeScript, and Vite**.

## 🌟 Features

- **Editorial Design System**: Curated typography with serif (`Fraunces`), sans-serif (`Inter`), and monospace (`JetBrains Mono`).
- **Instant Client-Side Navigation**:
  - `#home`: Hero, bio, portrait, education highlights, explore pathways, skills ledger, and recent milestones.
  - `#industry`: Career progression at Sparktech Agency (Back-End Developer, Junior Back-End Developer, Software Engineering Trainee).
  - `#projects`: Live web & mobile production projects (Deenyah, HavnProp.io, Training Plus, Oriboshi, Love of Sewing) with iOS App Store, Google Play Store, and live links.
  - `#publication`: Peer-reviewed research in *Springer Neural Computing and Applications (2025)* with live search and status filters.
  - `#research`: Machine learning research in model averaging, neural computing, and backend architecture.
  - `#news`: Career milestones, publications, and graduation history.
  - `#education`: BSc in CSE from AIUB, Notre Dame College Mymensingh, and Dean's List Awards.
  - `#contacts`: Direct channels including email (`mdnasifurahman@gmail.com`), phone (`+8801863960668`), WhatsApp (`01798552909`), LinkedIn, GitHub, and Google Maps embed.
- **Responsive Layout**: Full desktop navigation and mobile drawer menu with animated hamburger toggle.
- **Centralized Data**: All data is cleanly organized in [`src/data/portfolioData.ts`](./src/data/portfolioData.ts).
